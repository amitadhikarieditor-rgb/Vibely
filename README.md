 Vibely | Full-Stack Property Rental Platform

Tech Stack: Node.js, Express.js, MongoDB, Mongoose, EJS, Passport.js, Joi, HTML, CSS, JavaScript

* Developed a full-stack property listing platform inspired by modern vacation-rental applications, enabling users to create, view, edit, and delete property listings.

* Implemented **user authentication and authorization** using Passport.js, secure sessions, login/logout functionality, and protected routes.

* Designed **ownership-based authorization middleware** to ensure users can modify or delete only their own listings.
  
* Built complete **CRUD operations** for listings and integrated a review system allowing authenticated users to submit and manage reviews.
  
* Implemented server-side validation using **Joi** and Mongoose schema validation to maintain data integrity and prevent invalid submissions.
  
* Integrated **Express sessions and connect-flash** for persistent authentication state and user-friendly success/error notifications.
  
* Structured the backend using modular routes, middleware, controllers, and Mongoose models following RESTful development principles.
  
* Implemented search functionality across listing attributes including title, location, country, description, and price.
  
* Developed responsive EJS-based interfaces and handled HTTP method overriding for RESTful update/delete operations.
  
* Used Git/GitHub for version control and maintained the project through iterative debugging, feature development, and backend optimization.
